# SKILLS.md

## Proyecto

Página web moderna para promocionar y vender un pastel artesanal premium.

## Objetivo

Crear una experiencia visual atractiva que destaque el producto principal, aumente la confianza del cliente y facilite los pedidos.

---

# Stack Tecnológico

## Frontend

* Next.js 15
* React
* TypeScript
* Tailwind CSS
* Framer Motion

## UI/UX

* Diseño responsive
* Mobile First
* Accesibilidad WCAG básica
* Animaciones suaves

## Backend

* API Routes de Next.js
* Base de datos PostgreSQL (opcional)
* Prisma ORM

## Despliegue

* Vercel
* Dominio personalizado
